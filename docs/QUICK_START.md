# 🚀 Быстрый старт за 5 минут

## 1. Установка (30 сек)

```bash
pip install -r requirements.txt
```

## 2. Запуск (10 сек)

```bash
python app.py
```

Вы должны увидеть:
```
* Running on http://localhost:5000
```

## 3. Открыть в браузере

Перейди на `http://localhost:5000`

## ✅ Готово!

Теперь ты видишь работающее приложение с:
- ✅ Главной страницей
- ✅ Списком товаров
- ✅ Списком заказов
- ✅ Статистикой с графиками

## Основные функции

| Функция | URL | Описание |
|---------|-----|---------|
| Главная | GET / | Интегральная панель |
| Товары | GET /products | Список товаров |
| Добавить | POST /products | Через форму |
| Детали | GET /product/1 | Деталь товара |
| Заказы | GET /orders | Список заказов |
| Создать | POST /orders | Новый заказ |
| Статистика | GET /statistics | Графики |
| API Товары | GET /api/products | JSON |
| API Заказы | GET /api/orders | JSON |

## Первые шаги

### 1. Добавить товар
1. Нажми "Товары"
2. Нажми "Добавить товар"
3. Заполни форму
4. Готово!

### 2. Создать заказ
1. Нажми "Заказы"
2. Нажми "Новый заказ"
3. Выбери товар и заполни данные
4. Готово!

### 3. Посмотреть статистику
1. Нажми "Статистика"
2. Увидишь графики и метрики

## Часто используемые команды

```bash

flask shell

>>> from app import db
>>> db.create_all()

# Добавить товар
>>> from app import Product
>>> p = Product(name='Товар', price=100)
>>> db.session.add(p)
>>> db.session.commit()

# Выход
>>> exit()
```

## Если что-то не работает

### Порт занят
Измени в app.py: `app.run(port=5001)`

### БД заблокирована
```bash
rm app_database.db
python app.py  # Пересоздаст БД
```

### Модули не установились
```bash
pip install --upgrade pip
pip install -r requirements.txt
```
